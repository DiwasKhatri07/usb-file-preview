# Code of Conduct

## Our commitment

USB File Preview is maintained as a respectful, practical, and privacy-aware open-source project. We welcome contributors who help improve local file access, preview quality, accessibility, documentation, and developer tooling.

## Expected behavior

Participants should communicate clearly, assume good intent, respect different experience levels, and keep discussions focused on the project. Do not share private USB contents, credentials, malware, or files that someone has not authorized you to distribute.

## Unacceptable behavior

Harassment, discrimination, threats, deliberate exposure of private data, malicious code submissions, and disruptive personal attacks are not acceptable.

## Enforcement

Report conduct concerns privately to the repository maintainers through the contact method listed in the repository profile. Reports will be reviewed fairly and handled with appropriate confidentiality.
